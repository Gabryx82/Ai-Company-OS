# AI Company OS — Product Vision

AI Company OS is a local-first, Human-in-the-Loop control plane for managing software projects, AI agents, tools, knowledge, planning and external applications from one interface.

The system is not merely a multi-model chat UI. It is intended to become an operating environment where the user can:
- create and manage projects;
- assign specialized AI agents and subagents;
- manage skills, rules, tools, tool bundles and MCP connectors;
- generate and maintain project documentation and implementation plans;
- navigate code and project architecture visually;
- inspect pseudocode and source code through a Code Graph;
- maintain a secondary navigable memory / Knowledge Graph;
- plan daily, weekly and monthly work;
- coordinate GitHub/GitLab and team work through ClickUp;
- connect Google Drive and Gmail;
- manage templates and frameworks;
- launch or integrate development tools and external AI workspaces;
- monitor subscriptions, payment methods and model quotas;
- use voice commands and spoken responses;
- connect the existing 3D Omniverse ecosystem as a specialized department/workspace.

The user remains central to architecture, learning, approvals and validation.
